# Issue #26 Priority B/C Yaku Status

この文書は、Issue #26 のうち Priority B/C の標準役・レア役について、実装済み範囲と保留範囲を固定するためのメモです。

## 実装済み

| 役 | ID | 方針 |
| --- | --- | --- |
| 一気通貫 | `ittsuu` | 三麻で成立する筒子/索子の `123 + 456 + 789` のみ対象。萬子一通は牌構成上対象外。門前2飜、鳴き1飜。 |
| 三暗刻 | `sanankou` | 手牌内暗刻/暗槓を数える。ロンでシャンポン完成した刻子は暗刻にしない。 |
| 小三元 | `shousangen` | 三元牌2刻子 + 三元牌雀頭。役牌との複合は維持。 |
| 混全帯么九 | `chanta` | 全面子・雀頭が么九牌に関係し、順子を1組以上含む。純全帯么九とは二重計上しない。 |
| 純全帯么九 | `junchan` | 全面子・雀頭が老頭牌に関係し、字牌なし、順子を1組以上含む。 |
| 二盃口 | `ryanpeikou` | 門前限定。七対子としても読める形からも検出し、一盃口/七対子とは排他。 |
| 清老頭 | `chinroutou` | 1/9牌のみの役満。三麻で残る `1m/9m/1p/9p/1s/9s` が対象。 |
| 緑一色 | `ryuuiisou` | `2s/3s/4s/6s/8s/發` のみ。既定では發なしも可。`RuleConfig.yakuRules.ryuuiisouRequiresHatsu` で發必須にできる。 |
| 九蓮宝燈 | `chuuren-poutou` | 筒子/索子のみ。門前限定。萬子九蓮は三麻牌構成上対象外。 |
| 純正九蓮宝燈 | `chuuren-9-wait` | `winningTile` を除く13枚が九蓮基本形なら純正。`doubleYakuman !== false` で2倍役満。 |
| 三槓子 | `sankantsu` | 固定面子の槓情報から3槓子を検出。 |
| 四槓子 | `suukantsu` | 固定面子の槓情報から4槓子を役満として検出。 |
| 三色同刻 | `sanshoku-doukou` | 三麻牌構成上、`111m/111p/111s` または `999m/999p/999s` のみ対象。 |

## 保留

| 役 | RuleConfig | 保留理由 |
| --- | --- | --- |
| 人和 | `yakuRules.renhou = "disabled"` | 第一巡の鳴きなしロン、親/子、天和/地和との排他など、手牌だけでは判定できない文脈が必要。WinFlow/DrawContext側の初巡イベントと統合してから実装する。 |
| 流し満貫 | `yakuRules.nagashiMangan = "deferred"` | 流局時の全捨て牌、鳴かれたかどうか、流局精算との関係が必要。RoundLifecycleの流局精算実装と同時に扱う。 |
