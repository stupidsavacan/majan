# Offline Sanma Mahjong

完全オフラインで動作する、ブラウザ向け三人麻雀ゲームの土台版です。

現時点では、添付プロンプトの **Phase 1** の範囲だけを実装しています。

## 起動方法

- `index.html` をブラウザで開く
- ローカルサーバーを使う場合は、このリポジトリのルートで `python -m http.server 8000` を実行し、`http://localhost:8000` を開く

## Phase 1で実装済み

- 三麻用の牌定義
- `RuleConfig` 定義
- 山生成、シャッフル、配牌、ツモ、打牌
- 高打点モード時の五筒・五索全赤化
- 北抜き / 北通常牌 / 北なし の山構成切り替え
- プレイヤー1人 + CPU2人
- CPU仮ランダム打牌
- クリック / タップ操作
- 設定保存
- デバッグ表示

## ZIP取り込み

`uploads/` にZIPを置くと、workflowにより `extracted-zips/` 以下へ展開される構成です。
