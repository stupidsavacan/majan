# Phase 6 ブラウザ手動チェックリスト

## 起動とオフライン

- [ ] root `index.html` を直接開き、初期卓が表示される
- [ ] コンソールに `ReferenceError` や未処理例外がない
- [ ] 外部ネットワーク要求なしで表示・操作できる
- [ ] Yuji Mai埋め込みフォントで牌文字が表示される

## 基本操作

- [ ] `新しい局` で配牌し直せる
- [ ] 設定を変更・保存して新しい局へ反映できる
- [ ] 高打点モードで五筒・五索がすべて赤になる
- [ ] デバッグ画面で固定seedを適用できる
- [ ] 手牌をクリックして打牌できる
- [ ] タッチ操作相当で打牌できる
- [ ] CPU打牌後に人間の手番へ戻る

## デバッグ・分析・操作窓

- [ ] デバッグ画面にRuleConfig、牌枚数、和了形、役、点数、利用可能操作が表示される
- [ ] 呼び出し窓が出た場合、操作またはスキップで進行できる
- [ ] ロン・ツモの精算結果を表示して終了できる
- [ ] localStorageリセット後も新しい局を開始できる
- [ ] 壊れた設定JSONがあっても再読込で復旧できる

## 牌表示

- [ ] 牌面は暖色アイボリーで、背面は `#f8b500` 系
- [ ] 白に青い矩形枠がない
- [ ] 1mの「一」は size 0.41 / y 0.32、「萬」は size 0.39 / y 0.67
- [ ] 9mの「九」は size 0.37 / y 0.32、「萬」は size 0.39 / y 0.72
- [ ] 赤五筒・赤五索は赤く表示され、論理上は通常の5として判定される
