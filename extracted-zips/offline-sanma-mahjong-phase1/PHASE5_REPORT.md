# Phase 5 完了報告

## 実装した操作

- `Sanma.ActionResolver.getAvailableActions` を追加し、打牌・ツモ・ロン・ポン・チー・カン・リーチ・北抜きの利用可否と理由を返すようにしました。
- `Sanma.CallWindow` を追加し、CPU捨て牌後に人間がロン・明槓・ポン・チー・スキップを選べる呼び出し窓を実装しました。
- ロンは `HandAnalysis`、`YakuAnalysis`、`ScoreCalculator`、`Settlement` を通して点棒移動まで行います。
- CPUはPhase 5では鳴き・ロンを自動スキップします。

## 副露構造

ポン・チーは次の明示的な構造で `player.melds` に保存します。

```js
{
  type: "pon",
  tiles: [],
  fromPlayerIndex: 1,
  open: true
}
```

- ポンは他家の捨て牌と同一牌2枚を手牌から取り出します。
- チーは `allowChi: true` の場合のみ、上家の捨て牌に対して行えます。
- チー可能な順子は筒子・索子のみです。萬子・字牌のチーはできません。
- 鳴いた後はツモを行わず、鳴いたプレイヤーが打牌します。

## 呼び出し窓

- 優先順はロン、明槓、ポン、チーです。
- 人間に利用可能な操作がない場合は呼び出し窓を開かず、そのまま次のツモへ進みます。
- スキップ操作を必ず用意し、UIが停止しないようにしています。
- カンはPhase 5では判定・表示のみのため、呼び出し窓で選ぶと制限をログ表示してスキップします。

## リーチ

- 門前、聴牌、1000点以上、未リーチの場合に宣言できます。
- 宣言時に1000点を差し引き、供託を1本増やします。
- リーチ後のツモ切り制約、フリテン、一発、裏ドラの実処理は未実装です。

## カン

- `Sanma.KanManager` で暗槓・明槓・加槓候補を検出します。
- 呼び出し窓には対象捨て牌による明槓候補だけを表示します。
- 嶺上牌、槓ドラ、槍槓、安全な山・王牌更新が未整備のため、実行はPhase 5では行いません。

## 北抜き

- `northMode === "kita-dora"` かつ手牌に北がある場合のみ操作できます。
- 北を `player.kitaTiles` へ移し、通常山から補充牌を1枚ツモります。
- `northMode === "disabled"` でも例外を起こさず、操作不可として扱います。
- 抜き北枚数は将来の点数計算用 `kitaDoraCount` に渡します。
