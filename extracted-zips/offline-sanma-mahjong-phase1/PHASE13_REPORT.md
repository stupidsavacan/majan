# Phase 13 牌譜再生・成績強化レポート

## Replay capabilities
- `ReplayViewer` は保存イベントを先頭から再構築し、進む、戻る、先頭、末尾、自動再生、一時停止を提供する。
- 配牌、ツモ、打牌、副露、カン、抜き北、点数精算を手牌・河・副露・抜き北・点数ゾーンへ反映する。
- 局選択、局名、本場、親、現在イベント位置、イベント文を表示する。
- 配牌情報がない旧牌譜は部分再生として扱い、「この牌譜は古い形式のため、一部の表示を省略しています。」と表示する。
- 欠損イベントや範囲外プレイヤー番号は再生画面を停止させず、安全に読み飛ばす。

## Record list features
- `RecordIndex` が牌譜ID、作成日時、対局ID、最終順位、最終点、最高打点、タグ、schema version、JSONサイズを保持する。
- 牌譜一覧は新しい順で、文字検索、和了・敗北、役満・高打点の絞り込みに対応する。
- 詳細表示、選択牌譜JSONのコピー・エクスポート、検証付きインポート、確認付き個別削除を追加した。
- インデックス破損時は元データを退避し、保存牌譜から再構築する。
- 画面表示時は牌譜本文とインデックスのID整合性を確認し、古いインデックスが残った場合も再構築する。

## Stats definitions
- 対局成績: 対局数、1位回数、平均順位、平均最終点、最高最終点。
- 局成績: 和了、敗北、放銃、ツモ和了、ロン和了、最高得点、役満回数。
- 役成績: 役頻度、最多役、役満名。
- モード別: 高打点モード、チー許可、ツモ損のON・OFF・不明件数。
- 保存データに必要情報がない項目は、0を推測せず `null` と「集計不可」で表示する。

## Old-record compatibility
- Phase 8以降のversion 1・2牌譜を `GameRecord.normalize` 経由で読み込む。
- 表示に必要なイベントがない牌譜も一覧・詳細・部分再生を利用できる。
- JSONとして不正、IDなし、局なしの牌譜はインポートを拒否し、既存牌譜を変更しない。

## Storage limits
- 牌譜本文は既存方針どおり最新20件、1局300イベントに制限する。
- `offlineSanma.phase13.recordIndex` に軽量インデックスを保存する。
- 診断に牌譜サイズと4MiB接近警告を追加した。
